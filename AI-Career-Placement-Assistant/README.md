# 🎯 AI Career & Placement Assistant

A career preparation web application built with Python and Streamlit to help students analyze resumes, compare them with job descriptions, identify missing skills, and prepare for interviews.

## 🚀 Features

* Resume PDF text extraction
* Resume skill detection
* Job description skill extraction
* ATS-style keyword matching score
* Missing skill identification
* Role-based interview question generation
* Difficulty-based interview questions
* Simple and interactive Streamlit interface

## 🛠️ Tech Stack

* Python
* Streamlit
* PyPDF2
* Regular Expressions
* Git & GitHub

## 💻 Run Locally

```bash
git clone https://github.com/mehtakanika522-bit/ai-career-placement-assistant.git
cd ai-career-placement-assistant/AI-Career-Placement-Assistant
pip install -r requirements.txt
streamlit run app.py
```

## 🎯 Project Goal

The goal of this project is to help students understand how well their resume aligns with a target job role and identify practical skills they can improve for better placement preparation.

# 🎯 AI Career & Placement Assistant

An AI-oriented career preparation web app built with Python and Streamlit.

## Features
- Resume PDF text extraction
- Resume skill detection
- Job description skill extraction
- Job Match / ATS-style keyword score
- Missing skill identification
- Interview question generation by role and difficulty
- Clean Streamlit interface

## Tech Stack
- Python
- Streamlit
- PyPDF2
- Regular Expressions
- Git & GitHub

## Run locally

```bash
git clone https://github.com/YOUR-USERNAME/ai-career-placement-assistant.git
cd ai-career-placement-assistant
pip install -r requirements.txt
streamlit run app.py
```

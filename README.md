# AI Career Assistant 🤖

An AI-powered career assistant designed to help students prepare for placements through personalized career guidance, resume feedback, interview preparation, and skill recommendations.

## 🚀 Features

* AI-based career guidance
* Resume analysis and feedback
* Personalized interview questions
* Interview preparation assistance
* Skill-gap analysis
* Career and learning recommendations

## 🛠️ Tech Stack

* Python
* Streamlit
* Generative AI / LLM
* Pandas
* NLP

## 📌 How It Works

1. User provides their resume, skills, or career interests.
2. The system analyzes the provided information.
3. AI generates personalized feedback and recommendations.
4. User receives career guidance, interview questions, and improvement suggestions.

## 💻 Run Locally

```bash
git clone https://github.com/yourusername/ai-career-assistant.git
cd ai-career-assistant
pip install -r requirements.txt
streamlit run app.py
```
